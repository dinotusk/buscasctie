# Busca SCTIE — Demonstração

Protótipo independente e responsivo de busca por indicadores, gráficos e medicamentos da SCTIE, inspirado no Painel Modelo 03.

## Uso

Abra `index.html` no navegador ou publique o repositório em um serviço de hospedagem estática (como Vercel). Não requer build, dependências, banco de dados ou credenciais.

## Funcionalidades

- Busca por termos com normalização de acentos.
- Filtros por tipo e departamento.
- Cartões com gráficos ilustrativos, valores fictícios e prévia das ações.
- Links compartilháveis por parâmetros na URL.
- Layout responsivo e elementos básicos de acessibilidade.

**Atenção:** todos os dados e números são de demonstração. Os botões mostram uma prévia em vez de redirecionar para o Superset. A integração real requer catálogo validado, IDs de gráficos e URLs autorizadas. O projeto não modifica nem consulta o painel oficial.
